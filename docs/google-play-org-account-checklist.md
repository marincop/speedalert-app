# Google Play「組織帳號」申請 Checklist（台灣一人公司）

> 為什麼要辦組織帳號：**個人帳號（2023/11/13 後新增）** 上正式前要做「**封閉測試 12 位 × 連續 14 天**」。
> **組織帳號免除這條**，一人公司最推薦。

---

## 0. 先確認你符合組織帳號條件
- 有 **公司 / 行號 登記**（統一編號）
- 建議先備好 **公司英文名稱**（與 D-U-N-S 一致）

## 1. D-U-N-S 號碼（免費）
1. 先查公司是否**已有** D-U-N-S（很多公司其實已有）：
   - 鄧白氏台灣 https://www.dnb.com.tw  → 查詢
2. 沒有就申請（免費；也可從 Google Play 註冊流程內的連結申請）：
   - 鄧白氏台灣 https://www.dnb.com.tw/Marketing/DUNSNO/
   - 需要填：**法定中文名 / 英文名、統一編號、登記地址、電話、聯絡人**
3. 等待核發：**約 1–5 個工作天**

> ⚠️ **最重要**：D-U-N-S 上的 **法定名稱與地址**，必須和你之後在 **Google Payments 付款資料**填的**完全一致**。
> 不一致 → Google 給你 **28 天**修正，逾期會**移除帳號與 App**。

## 2. Google Play Console 註冊（組織）
1. 到 https://play.google.com/console → 開始註冊
2. 帳號類型選 **「組織 (Organization)」**（不是個人）
3. 填：
   - 組織**法定名稱**、**地址**（= D-U-N-S）
   - **D-U-N-S 號碼**
   - 網站 / 電話 / 聯絡 Email（建議用公司網域）
4. 建立 **Google Payments** 付款資料
5. 付 **US$25（一次性）**

## 3. 開發者驗證（2026 起 Play 全面要求）
準備以下文件備查（Google 可能要求上傳）：
- [ ] **公司登記證明**（設立登記表 / 核准函）
- [ ] **統一編號**
- [ ] **公司地址證明**（近 3 個月：水電帳單 / 銀行對帳單 / 稅單）
- [ ] **負責人身分證明**（身分證或護照）
- [ ] 公司**英文名稱**（與 D-U-N-S 一致）
- [ ] 公司 Email、電話
- [ ] 信用卡（付 $25）

## 4. 上架前要準備的素材（可並行）
- [ ] **隱私權政策網址**（有存取定位 → 必填）
- [ ] App 圖示 **512×512**
- [ ] 手機**截圖** 2–8 張
- [ ] **Feature Graphic 1024×500**
- [ ] 簡短說明（80 字內）+ 完整說明
- [ ] 應用程式分類（導航/地圖 或 旅遊與在地）
- [ ] **簽章 keystore**（`.jks`）+ 產出 **AAB**
- [ ] 資料安全 (Data safety) 表單
- [ ] **位置權限宣告**（我們用定位；若含背景定位，Google 可能要求示範影片）

## 5. 時程預估
| 項目 | 時間 |
|---|---|
| D-U-N-S 核發 | 1–5 工作天 |
| Play 帳號 + 驗證 | 數天（可能更久） |
| 首次上架審核 | 數天 |
| 組織帳號封閉測試門檻 | **免除** ✅ |

## 6. 技術待辦（我們這支 App）
- [ ] `build.gradle.kts` 加 `signingConfigs`（金鑰放 `keystore.properties`，**不進版控**）
- [ ] `./gradlew :app:bundleRelease` 產 **signed AAB**（Play 只收 AAB）
- [ ] CI 自動出 AAB
- [ ] 隱私權政策頁（可放 GitHub Pages）
- [ ] 決定定位策略：**保留背景定位**（要影片說明）或**改成僅「使用中」**（過審容易）
